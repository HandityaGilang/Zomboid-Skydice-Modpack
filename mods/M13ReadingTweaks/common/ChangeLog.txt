Version Denotation:
-------------------
This information will most likely not be important for most people, but it helps me keep my sanity :P (i also wonder how many people will read this...)

A.B.C.DE-B42UNSTABLE
A.B = Mod Main version
C = Unstable Branch denotifier, for example 18 = 42.18
D = Mod Sub-version - Added/Removed Features that change how the mod behaves ingame
E = Mod Hotfix version - Hotfixes for issues (and also small changes to the mod that don't reflect ingame, like adding this changelog to the mod)

[ Version: 1.3.15.0-B42UNSTABLE ]
- Mod Updated to work with 42.15
Note: When i read that Indie Stone added a 10% reading speed bonus into the game, I almost decided to stop developing this mod.
But then i noticed this bonus does NOT apply to sitting in vehicles AND the speed bonus is not configurable...
So i decided to update the mod to complement these changes.

Changes:
- Mod now works with Multiplayer!
- Changed how PSM (Player Sitting Multiplier) is applied to player's total reading speed.
- PSM now also works for sitting in vehicles
- Updated Translation files
