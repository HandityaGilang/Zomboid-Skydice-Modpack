GORE'S SVU4 VANILLA CARS
========================
Mod ID: GoresSVU4VanillaCars
Workshop ID: 3742291546
Version: 1.7
Project Zomboid: Build 42.20
Requires: GoresSVU4Core

COMPATIBILITY
-------------
- Uses the Build 42 versioned mod structure.
- Declares Project Zomboid 42.20 as both its target and minimum version.
- Adds vehicle-specific SVU4 armour and upgrade visuals to the supported
  vanilla vehicle fleet.
- Includes the Build 42.20 SportsCar and RaceCar tyre-chain refresh correction.
- Corrects pickup and van armour mesh-path casing for Linux dedicated servers.
- Corrects paper-rusted armour models to use the packaged rusted texture.
- Prevents stable vehicles from being repeatedly repainted by proximity
  refreshes.
- Preserves the completed RaceCar armour and upgrade alignments.

VALIDATION
----------
- Single-player vehicle, installation, removal and visual-refresh coverage is
  complete.
- Multiplayer and dedicated-server coverage should be completed before upload.
